# Elegant Markdown to PDF Example

This is a generic example demonstrating the professional layout capabilities of this tool.

## 1. Professional Typography
The tool uses system fonts for maximum readability and crisp PDF output. Bold text like **this** and *italics* are rendered beautifully.

## 2. Unbreakable Blocks
This paragraph is protected by CSS rules. It will never be split across two pages. If the content is too long for the current page, the entire paragraph moves to the next one.

## 3. Side-by-Side Layouts (Flexbox)
You can create professional multi-column layouts using standard HTML `div` tags:

<div class="flex-container">
  <div class="flex-item">
    <b>Key Benefits:</b>
    <ul class="data-list">
      <li>No page-break orphans</li>
      <li>Clean data tables</li>
      <li>Fast regeneration</li>
    </ul>
  </div>
  <div class="flex-item">
    <b>Comparison Table:</b>

  </div>
</div>
